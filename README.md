# GeoSense Agent — Phase 1

GeoSense Agent is a geospatial AI project for identifying promising locations using geospatial features and machine-learning models.

## Phase 1 Status

Phase 1 implements the core geospatial data pipeline, feature engineering, machine-learning training, SHAP explainability, site scoring, and automated tests.
